# NBG 3 als iPhone-App (PWA)

## Dateien
- index.html: die eigentliche App
- manifest.json: App-Name, Icon und Darstellung
- sw.js: Offline-Unterstützung
- icon-180.png / icon-512.png: App-Icons

## Installation auf dem iPhone
1. Die Dateien auf einen Webserver / GitHub Pages hochladen.
2. Die Adresse der `index.html` in Safari öffnen.
3. Teilen → „Zum Home-Bildschirm“.
4. „Hinzufügen“ auswählen.
5. Danach lässt sich NBG 3 wie eine normale App öffnen.

Wichtig: Für „Zum Home-Bildschirm“ muss die Seite über HTTPS erreichbar sein.
GitHub Pages ist dafür kostenlos und geeignet.
